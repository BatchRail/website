Hosted facilitator (Base Sepolia)

How to use the public test facilitator at facilitator.batchrail.io.

Testnet only. Network eip155:84532. No API key required for the current public demo. The facilitator wallet pays gas for relayed on-chain actions.

Required config

FACILITATOR_URL=https://facilitator.batchrail.io

Use network eip155:84532 in your payment requirements.

Endpoints

PathMeaning
/healthService is up; basic network info
/statsPublic aggregate usage counters
/supportedSchemes & networks this facilitator supports
POST /verifyCheck a payment payload without spending gas
POST /settleSubmit deposit / claim / settle / refund on-chain

Stats: https://facilitator.batchrail.io/stats

Minimal resource server

import { HTTPFacilitatorClient } from "@x402/core/server";
import { BatchSettlementEvmScheme } from "@x402/evm/batch-settlement/server";
import { x402ResourceServer } from "@x402/express";

const NETWORK = "eip155:84532";
const payTo = process.env.EVM_ADDRESS; // your receive address

const facilitatorClient = new HTTPFacilitatorClient({
  url: "https://facilitator.batchrail.io",
});

const batchScheme = new BatchSettlementEvmScheme(payTo);
const resourceServer = new x402ResourceServer(facilitatorClient)
  .register(NETWORK, batchScheme);

Protect routes with scheme: "batch-settlement", network: "eip155:84532", and your payTo.

Full examples: github.com/BatchRail/core.

Gas & wallets

  • Facilitator — operator wallet; pays Base Sepolia gas
  • payTo — your address; receives settled USDC (no ETH required)
  • Payer / client — needs Base Sepolia USDC to open a channel

USDC (Base Sepolia): 0x036CbD53842c5426634e7929541eC2318f3dCF7e

Optional API key

If the operator enables API_KEY, send X-API-Key: … or Authorization: Bearer …. /health and /stats stay public. Until that env var is set, the demo remains open.
