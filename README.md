# BatchRail

**x402 facilitator + managed channel layer for batch-settlement.**

Exact-scheme facilitator fees are often ~$0.001 per onchain settle. On ~$0.02–$0.03 calls that is a few percent of GMV — and it grows with volume. Batch-settlement verifies off-chain and settles in bulk.

Public site: [batchrail.io](https://batchrail.io)
